# DevStack Bangla: tutorial source code

Source code for the videos on the YouTube channel [DevStack Bangla](https://www.youtube.com/@devstackbangla):
Bangla tutorials on .NET and C#, ASP.NET Core, Angular, SQL Server, PostgreSQL, Node.js and AI, for students,
junior and working developers.

DevStack Bangla চ্যানেলের ভিডিওগুলোর source code। প্রতিটা ভিডিওর description-এ এখানকার folder-এর link আছে।

Each zip is the project that ran in its video: the code, the commands and their output on screen come from it.

## How to use

1. Open the video's folder in `src/` (the link in the video's description goes there).
2. Click `source.zip`, then "Download raw file", and unzip it.
3. Follow the folder's README: what is inside, the versions used and how to run it.

The JobTrack videos are one full-stack series (ASP.NET Core Web API + Angular + SQL Server). Each episode's zip is
the whole project at the end of that episode, so you can start from any episode.
